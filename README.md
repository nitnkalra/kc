# KC Leaderboard

## Create venv

```bash
python -m venv venv
```

## Activate

Windows

```bash
venv\Scripts\activate
```

## Install

```bash
pip install -r requirements.txt
```

## Update config.py

Set:

SEASON_FOLDER

## Run

```bash
python main.py
```

- Leaderboard.xlsx
- Session_History.xlsx

Season_5/outputs
