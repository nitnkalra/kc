# Knowledge Club Website - Frontend

Static site built with **Astro 5 + Tailwind CSS v4 + Chart.js**, deployed to
**GitHub Pages** by `.github/workflows/deploy.yml` (repo root).

Live: https://nitnkalra.github.io/kc/

## Structure

```
src/frontend/
├── package.json            <- Node version (engines) + package versions (single source)
├── package-lock.json       <- generated from package.json - never edit by hand
├── astro.config.mjs        <- site URL + base path (/kc)
├── public/logo.png
└── src/
    ├── pages/index.astro   <- the page
    ├── components/         <- Program.astro
    ├── styles/global.css   <- brand theme + animations
    └── data/
        ├── kc.json             <- static text: about, mission, programs, insights (edit by hand)
        ├── sessions.json       <- GENERATED by backend
        ├── leaderboard.json    <- GENERATED by backend
        ├── last_season.json    <- GENERATED by backend
        └── scoring.json        <- GENERATED from backend config/scoring_rules.py
```

Never edit the GENERATED files - they are overwritten by `src/backend/main.py`.
To change points, edit `src/backend/config/scoring_rules.py` and re-run the backend.

## Run locally (Node 22)

```bash
cd src/frontend
npm ci            # exact versions from package-lock.json
npm run dev       # http://localhost:4321/kc/
```

## Upgrade a package

1. Change the version in `package.json` (exact version, no `^`).
2. `npm install` - updates `package-lock.json`.
3. Commit both files together. The deploy uses `npm ci`, which fails if they are out of sync.

## Deploy

Automatic: merge PR `qa -> main`. Any change under `src/frontend/` triggers the
GitHub Actions deploy (~1-2 min). Manual: Actions -> Deploy landing page -> Run workflow (`main`).

`insights` in `kc.json` currently holds SAMPLE values.
